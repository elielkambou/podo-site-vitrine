# Origine des visuels

- Illustration du pied : SVG original écrit pour le site dans `src/components/foot-visual.tsx`. Schéma pédagogique stylisé, sans mesure réelle et sans donnée patient.
- Signe et logo : SVG originaux dans `app/icon.svg` et `public/brand/logo.svg`.
- Image Open Graph : générée à partir de texte et de couleurs originaux dans `app/opengraph-image.tsx`.
- Police Manrope : chargée par `next/font/google` lors du build ; vérifier ses conditions de licence si la chaîne de publication change.

Aucune photo, capture de patient, banque d’images ou modèle 3D externe n’est inclus.
